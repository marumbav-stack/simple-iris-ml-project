
# Iris Flower Classification Using Machine Learning

## Introduction
This project uses machine learning to classify iris flowers into
three types: Setosa, Versicolor, and Virginica.

## Objective
The objective is to train a model that predicts a flower's type
using its measurements.

## Tools Used
- Python
- Scikit-learn
- Decision Tree Classifier

## Dataset
The project uses the built-in Iris dataset from scikit-learn.
The dataset contains measurements of iris flowers.

## Methodology
1. Load the Iris dataset.
2. Separate the measurements from the flower labels.
3. Split the dataset into training and testing sets.
4. Train a Decision Tree model.
5. Test the model and calculate its accuracy.
6. Predict the type of a sample flower.

## How to Run
Install the required library:

    python -m pip install -r requirements.txt

Run the program:

    python main.py

## Conclusion
This project demonstrates the basic machine learning process
of preparing data, training a model, testing predictions,
and evaluating model performance.
